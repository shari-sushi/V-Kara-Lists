# ページ下部の空白修正

## 背景・目的

Issue #364: topページや登録ページの下部に謎の空間がある。

PR #366 で `Layout.tsx` の `Footer` コンポーネントは `videoState.position === "footer"` の時だけ
スペースを確保するよう修正済みだが、本番では依然として空白が残っている（Issueコメントより）。

原因は `VideoLayout.tsx` の `#vkaraoke-player` 要素側にあった。

```tsx
<div id="vkaraoke-player" className={`${isAbsolute ? "none" : "fixed"} z-30`} style={{ ...FOOTER_POSITION }}>
```

`isAbsolute`（`position === "in-content"`、初期値かつ大半のページで該当）のとき `className` に
`"none"` を付与しているが、Tailwind に `none` という display ユーティリティは存在しない
（`display: none` は `hidden` クラス）。そのため実際には非表示にならず、
`style={{ height: 200, width: 356, bottom: 0, left: 0 }}` を持つ要素が通常のドキュメントフローに
残り続け、ページ下部に空白を生んでいた。

PR #366 の計画時点では「VideoLayout.tsx の外側 div はスペースに影響しない」と判断されていたが、
実際には内側の `#vkaraoke-player` div自体が原因だった。

## 変更スコープ

- 変更ファイル: `t0016Next/myapp/src/components/layout/VideoLayout.tsx`
- 影響範囲: `_app.js` で全ページに描画される `VideoLayout` のみ。表示ロジックの変更のみで機能追加はなし。

## 実装ステップ

1. `VideoLayout.tsx` の `className` で `isAbsolute` が true のときに使う値を `"none"` から `"hidden"` に修正する
