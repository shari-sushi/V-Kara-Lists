# 背景色をOSのライト/ダーク設定に依存させない

## 背景・目的

濃い緑（`#1f2724`）の背景が `@media (prefers-color-scheme: dark)` の中でしか指定されておらず、ライトモードの端末（iPhone/iPad の Safari など）では Next.js テンプレート由来の薄い灰色（`214, 219, 220`）と黒文字になっていた。
いずれライトモードを実装する予定なので、色の定義を CSS 変数に集めた形は残したまま、当面はライト/ダークに関係なく同じ配色にする。

## 変更スコープ

- `t0016Next/myapp/src/styles/global.css`
- 見た目への影響: ライトモードの環境で背景・文字色・ネイティブ部品（スクロールバー等）がダークモードと同じになる。ダークモードの環境では変化なし

## 実装ステップ

1. `:root` の色変数を、これまでダークモード用だった値にする
2. `@media (prefers-color-scheme: dark)` の分岐を削除する
3. `color-scheme: dark` を `:root` で常に指定する
4. ライトモードを足すときの上書き方法を `:root` にコメントで残す

## 完了条件

- [ ] ライトモードでもダークモードでも背景が `#1f2724`、文字が白になる
- [ ] `npm run build` / `npm run lint` が通る

## 注意事項

- `tailwind.config.js` の `darkMode: true` は Tailwind v3 の正しい値ではないが、`dark:` クラスを使っていないため今回は触らない。ライトモード実装時に切り替え方式（OS追従 or トグル）と合わせて `'media'` / `'class'` を決める
- `html { background: #252525; }` はヘッダーと同色で、iOS Safari の上端のバウンス時に見える色。今回は変更しない
