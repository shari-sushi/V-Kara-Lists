# ライブ(category=32)の一覧・登録・編集・削除を歌枠と同じUIで実装

## 背景・目的

#458 で歌枠(31)の画面を新データモデルで復元したが、ライブ(32)は `/videos/live` で「現在開発中」のままになっている。
DB(`videos.category`)・API(`POST /create/videos` は 32 を許可、ライブは複数曲カテゴリ)は対応済みなので、フロントだけで歌枠と同じUIを提供する。

関連issue（ライブ専用ではないため close しない）: #264 / #135 / #278

## 合意した仕様

- 登録: 既存の登録画面の「動画」登録に「歌枠／ライブ」の選択欄を追加する（ライブ専用ページは作らない）
- トップ・VTuberページ・マイページ: 歌枠のみのまま
- DB・バックエンドの変更なし

## 変更スコープ

- `t0016Next/myapp/src/` のみ
  - 一覧: `/sings/karaoke` の中身を共通コンポーネントに切り出し、`/videos/live` でライブを表示する（pathは既存のまま。新設しない）
  - フィルタ: `filterKaraokeCategory` をカテゴリ指定の関数に一般化し、CRUD画面用に複数曲カテゴリ(31/32)の絞り込みを追加
  - 登録: 動画登録にカテゴリ選択（歌枠/ライブ）
  - 編集: 動画編集でカテゴリを 31⇔32 で変更できるようにする（#455 で同グループ内の変更は許可と整理済み）
  - 削除: 歌枠とライブの両方を対象にし、表記を「動画」に
  - 動画のドロップダウン: ライブには【ライブ】を付けて区別する

## 実装ステップ

1. `util/videoCategory` に `filterByCategory` / `filterMultiSongCategory` を追加
2. 一覧の共通コンポーネント作成、`/sings/karaoke` と `/videos/live` から利用
3. 登録・編集フォームにカテゴリ選択を追加
4. CRUD画面(create/edit/delete)のフィルタを複数曲カテゴリに変更
5. lint / build
