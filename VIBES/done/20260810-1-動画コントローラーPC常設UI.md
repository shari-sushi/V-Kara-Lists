# 動画コントローラー(PC用)の常設UI実装

## 背景・目的

Issue #296「ページ遷移しても再生動画が維持されるように」の調査コメントにより、`VideoProvider` / `VideoLayout` / `_app.js` への常時マウントという基盤は実装済み(#297)であることが判明した。
一方で `VideoLayout.tsx` には「動画のコントローラーをここに配置」というTODOが残ったままで、再生/一時停止の操作手段が無く、`VideoProvider.setIsPlaying` もどこからも呼ばれていなかった。

一覧/詳細ページ側からの再生開始導線(`updateVideo`の呼び出し)は、DB再設計(#398)に伴い一覧UI自体が `DevelopingContentPage` のプレースホルダーのままのため未着手・別issue待ち。
また `VideoPlayerAltBox` の実体化・座標連携は Issue #299 として切り出され、担当者(shari-sushi)がアサイン済みのため本対応では扱わない。

本対応では、Issue #298「ページ遷移しても残るUIを作る(PC用)」に相当する範囲として、footerプレイヤーに隣接する形でPC(md以上)向けの再生コントローラーを実装する。

## 変更スコープ

- `t0016Next/myapp/src/components/moviePlayer/ReactPlayer.tsx`: `playing` propを受け取れるようにする
- `t0016Next/myapp/src/components/layout/VKaraVideoPlayer.tsx`: `videoState.isPlaying` をプレイヤーに渡す
- `t0016Next/myapp/src/components/layout/VideoController.tsx`: 新規。再生/一時停止・位置切り替えボタンを持つPC用コントローラー
- `t0016Next/myapp/src/components/layout/VideoLayout.tsx`: `VideoController` を配置

## 実装ステップ

1. `ReactPlayer.tsx` の `playing` を固定値からprops経由に変更する
2. `VKaraVideoPlayer.tsx` から `videoState.isPlaying` を渡す
3. `VideoController.tsx` を作成し、`setIsPlaying` と既存の `ToggleVideoPositionButton` を使って再生/一時停止・位置切り替えを行えるようにする
4. `VideoLayout.tsx` に動画がロードされている場合のみ `VideoController` を表示する(md以上のみ表示)

## 完了条件

- [ ] `npm run build` / `npm run lint` が通る
- [ ] 動画再生中に一時停止/再生ボタンで `ReactPlayer` の再生状態が切り替わる

## 注意事項

- 一覧/詳細ページからの再生開始導線(`updateVideo`の呼び出し)は本対応のスコープ外(一覧UI未実装のため)
- `VideoPlayerAltBox` の実体化・座標連携(in-content位置での実表示)はIssue #299のスコープのため対応しない
