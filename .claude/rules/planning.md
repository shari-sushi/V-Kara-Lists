# 実装計画 (VIBES) ルール

## 計画ファイルの保存場所

`VIBES/plan/` ディレクトリに保存する。

## ファイル命名規則

```txt
YYYYMMDD-{連番}-{簡潔な作業内容}.md
```

### 例

```txt
VIBES/plan/
├── 20260218-1-カラオケ一括登録機能.md
├── 20260218-2-VtuberページUI改善.md
└── 20260219-1-お気に入り機能バグ修正.md
```

## 計画ファイルの構成

計画ファイルには以下を含める:

```markdown
# {タイトル}

## 背景・目的

なぜこの変更が必要か

## 変更スコープ

- 変更するファイル・ディレクトリ
- 影響範囲

## 実装ステップ

1. 手順1
2. 手順2
3. ...

## 完了条件

- [ ] 条件1
- [ ] 条件2

## 注意事項

気をつけること・既知の制約
```

## vibeコーディングの進め方

1. **計画作成**: ユーザーと仕様を合意し、VIBES/plan に計画ファイルを作成する
2. **実装**: 計画に沿って実装する。計画外の変更は最小限にする
3. **確認**: `npm run build` / `go build` / `go test` が通ることを確認する
4. **完了報告**: 何を変更したかを簡潔に報告する
5. **完了移動**: PR がマージされたら計画ファイルを `VIBES/done/` に移動する

## 注意

- 計画なしに大きな実装を始めない
- 計画と実装が乖離した場合は計画ファイルを更新する
- 1ファイル = 1つのタスクにする（複数タスクは連番で管理）
